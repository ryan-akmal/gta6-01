# SOLMAR HEAT — Make GTA 6

**make.fun competition:** `gta6-01` — "Make GTA 6"
**Entry title:** SOLMAR HEAT

An original open-world crime game, playable in a desktop browser from static
files with no network request. All city, characters, vehicles, names, story,
art, sound and music are original — nothing from Rockstar Games.

## What is in the game

- A drivable city, on foot and by car — 7 cars to steal and drive
- Traffic and pedestrians
- Wanted level 0–5 stars, with police chases
- 5 missions with a story, from picking up a passenger to police chases
- Combat on foot, HUD with minimap, start screen and save
- Visual polish: soft shadows, warm-lit windows, lamp glow, detailed cars, sea sparkle

## Controls

- WASD — walk/drive, Shift — run, E — enter car
- Mouse — shoot, F — punch, M — mute, P — pause

## How to run

```sh
node serve.ts   # serves the game locally, then open it in a desktop browser
```

Screenshots from a real play session are in `screenshots/`.
